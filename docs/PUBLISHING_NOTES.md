# 发布与复现说明

## 已整理的内容

完整综合项目及小型工具位于 projects；基础编程、外设、网络与控制实验位于 coursework；原生硬件设计位于 hardware；只有报告/开题材料的技术主题位于 docs，并明确标注文档性质。

## 不进入公开仓库的内容

- 依赖环境、node_modules、虚拟环境、厂商完整 SDK 与解包运行库。
- HEX/AXF/ELF、EXE/DLL/JAR、编译目录、下载工具及安装包。
- 数据集、模型权重、照片/录像、日志、数据库和上传附件。
- 云平台/邮箱鉴权值、真实病历、通讯录数据、个人简历与证件照。
- 课程 PPT、参考试卷、答案库、整套商业工具库及非技术语言/数学资料。

MySQL 目录原来主要为 Workbench/服务端运行文件，属于工具依赖；业务 schema 已归入班级门户。English、French、Math、Work 中的非开发材料不冒充软件项目；Write 中的技术开题作为研究记录索引。重复的 ClassContactsSystem、Z-Stack SDK、提取出的可执行运行库不重复发布。

## 本地配置

发布副本中原有云平台/邮箱密钥已换成占位值。OneNET 项目请在项目 UI 或对应源码配置位置填写自己的产品、设备与 token；Java 班级门户数据库密码改由 CONTACTS_DB_PASSWORD 环境变量读取。不要直接使用作者原环境的账号或设备。

Python requirements 根据公开源码的 import 汇总，仅作为依赖清单起点；硬件库依赖目标操作系统。少量历史代码仍需按各 README 的入口、板卡、传感器驱动和源模型版本检查。缺少 SDK、外部数据或真实设备时，文档会明确说明，不能将静态整理视为实机验收。

## 原生设计与第三方来源

SchDoc/PcbDoc、DWG、Multisim 和 Packet Tracer 文件需兼容的原生工具打开，外部库链接可能需要本机重新关联。保留原始来源与版权标记；仓库没有为第三方资产重新授权，详见 NOTICE.md。
