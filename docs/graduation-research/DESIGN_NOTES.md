# 课程设计说明摘要

以下根据本地课程报告整理，仅作功能与实验方法说明，不替代复现实测。

基于边缘视觉与本地大模型的智慧养老异常行为感知与主动关怀系统设计与实现

随着人口老龄化持续发展，独居老人及居家养老人群对连续安全监护、异常事件及时发现和日常关怀提出了更高要求。传统方案往往依赖人体红外、门磁或环境传感器等单一数据源，难以准确理解复杂行为；集中式云端视频分析又受到网络延迟、带宽成本和隐私保护等因素制约。针对上述问题，本课题拟设计并实现一套基于边缘视觉与本地大语言模型的智慧养老异常行为感知与主动关怀系统。系统采用“端—边—云”架构：端侧利用微控制器采集人体红外、惯性、门磁、烟雾及温湿度等数据；边缘侧通过Python接入多源数据，采用YOLOv8开展人员检测，并结合姿态/时序特征或规则判定实现跌倒、长时间滞留等事件识别，再与传感器状态进行时间窗口关联和风险分级；本地通过Ollama运行大语言模型，根据结构化事件上下文生成面向家属或照护人员的风险说明与关怀建议；云侧采用Web平台和数据库完成用户、设备、事件、告警及历史记录的管理与展示。课题将重点验证多源感知与风险融合的有效性、边缘推理实时性、告警可靠性以及本地模型输出的可控性，形成具有可演示性和可扩展性的原型系统。

关键词：智慧养老；物联网；边缘计算；YOLOv8；本地大语言模型；多模态感知；异常行为检测

本课题旨在实现一个可运行、可验证的智慧养老原型系统，打通从传感器采集、视觉事件识别、多模态风险判断、本地语义解释到Web告警管理的完整流程。系统重点关注跌倒和异常滞留等安全事件，并兼顾烟雾及居住环境异常；通过边缘端优先处理原始视频和传感器数据，降低对持续云连接的依赖；通过规则化风险决策与本地大模型辅助表达相结合，提高告警信息的可理解性和主动关怀能力。

视觉方法通过图像、视频或人体关键点描述行为状态，能够减少对老人持续佩戴设备的依赖。Alam等对深度学习视觉跌倒检测研究进行了综述，并讨论相关数据集与评价指标，指出深度学习已成为该方向的重要技术路径[3]。近年来，YOLO系列模型因推理流程相对简洁，常被用于目标检测任务；官方文档说明，目标检测模型输出目标边界框、类别标签和置信度，且支持使用自定义数据进行训练和验证[8]。需要明确的是，通用YOLOv8模型本身并不自动具备可靠的“跌倒”语义类别。实现跌倒识别仍需针对任务标注数据、训练自定义检测/姿态模型，或将人体姿态、垂直高度变化、运动速度和连续帧时序规则组合使用。

设计并实现一套以微控制器和环境传感器为端侧采集基础、以Python边缘服务和YOLOv8视觉分析为核心、以Ollama本地大语言模型为语义辅助、以Web平台和数据库为管理支撑的智慧养老异常行为感知与主动关怀系统。系统能够完成多源数据接入、异常事件识别和关联、风险分级、告警推送、关怀建议生成及历史记录查询，并通过测试验证主要功能和基本性能。

6. Web管理平台与数据库。实现用户/住户资料管理、设备在线状态、传感器实时值、异常事件列表、告警确认、历史记录、统计可视化和模型关怀建议展示；设计用户权限、操作日志、数据保留规则和必要的备份机制。

系统采用“端侧采集—边缘分析—云侧管理”的分层架构，各层通过标准化数据接口解耦，便于单独调试和后续扩展。

系统可分阶段开发：首先验证传感器读数和Web入库，其次完成视频人员检测与事件规则，再实现融合、告警和本地大模型解释，最后开展联调与测试。对算力和数据集的需求可以通过选择较小模型、降低推理分辨率、复用公开数据和构造模拟事件进行控制。最终实现范围应以实际硬件条件为准，优先保证端到端流程可运行。
