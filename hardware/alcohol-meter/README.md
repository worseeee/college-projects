传感器信号采集与显示电路。

**性质**：电子/传感器硬件课程设计。

## 功能与实现

- 传感器信号采集与显示电路。
- 按实际保留文件提供原理图/PCB 源工程；缺失的板图不额外声称已完成。

- `实验项目二.PcbDoc`
