# 单片机实验板原理图与 PCB

8051 训练板的原理图和 PCB 设计。

**性质**：电子/传感器硬件课程设计。

## 功能与实现

- 8051 训练板的原理图和 PCB 设计。
- 按实际保留文件提供原理图/PCB 源工程；缺失的板图不额外声称已完成。

## 目录与入口

- `DESIGN_NOTES.md`
- `单片机实验板电路原理图.PcbDoc`
- `单片机实验板电路原理图.PrjPCB`
- `单片机实验板电路原理图.SchDoc`

## 环境与运行

使用兼容原文件版本的 Altium Designer 打开 .PrjPCB、.SchDoc 或 .PcbDoc；项目引用的外部器件/封装库需在本机重新关联。

## 验证范围与复现说明

- 没有打包整套 Altium 商业元件库、历史备份与自动预览。
- 源工程为课程设计记录，未将其声明为量产验证或认证硬件。
