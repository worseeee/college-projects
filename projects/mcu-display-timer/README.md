# 8051 LCD 显示与定时

按当前保留的源文件记录 LCD1602 初始化、字符显示和 Timer0 计时功能。

**性质**：单片机课程设计源码版本。

## 功能与实现

- Keil C51 工程、LCD 读写及忙检测封装。
- 主循环与 Timer0 定时显示配合。

## 目录与入口

- `STARTUP.A51`
- `设计.c`
- `设计.uvproj`

## 环境与运行

使用 Keil C51 / 8051 打开本目录工程配置（若提供），并安装目标芯片及课程板卡对应的依赖。仅发布应用层文件时，将其合并回原厂 SDK 的同名应用目录后再构建。不要把应用源码目录直接当成完整厂商 SDK。

## 验证范围与复现说明

- 对应课程报告描述的环境采集系统更大，但当前入口主要是 LCD 与计时，不以报告范围代替代码实现。
- 演示学号已替换为全零样例。
