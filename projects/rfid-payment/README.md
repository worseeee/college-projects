# RFID 刷卡扣款演示

在 STC89C52 与 MFRC522 开发板上演示寻卡、鉴权、读写卡块、余额更新和 LCD 提示。

**性质**：8051 / MFRC522 课程设计。

## 功能与实现

- 主程序 `MAIN.C` 组织按键、金额输入、卡片操作与蜂鸣器提示。
- RC522 驱动经 SPI 完成寻卡、防冲突、选卡与块读写。
- LCD1602 显示初始化、余额和扣款状态。

## 目录与入口

- `firmware/MAIN.C`
- `firmware/MFRC522.H`
- `firmware/RC522.C`
- `firmware/lcd1602.c`
- `firmware/lcd1602.h`
- `firmware/lhj.uvproj`

## 环境与运行

使用 Keil C51 / STC89C52 打开本目录工程配置（若提供），并安装目标芯片及课程板卡对应的依赖。仅发布应用层文件时，将其合并回原厂 SDK 的同名应用目录后再构建。不要把应用源码目录直接当成完整厂商 SDK。

## 验证范围与复现说明

- 需要对应开发板、MFRC522、LCD1602、测试卡与编程器。
- 默认测试卡密钥和卡块余额是教学演示，不作为真实电子支付或安全钱包。
