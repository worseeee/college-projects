# 实验室设备借还桌面应用（基础版）

基于 Tkinter、Device/DeviceManager 与文本文件保存，演示设备借还与操作记录。

**性质**：Python 期末课程设计。

## 功能与实现

- 设备对象、借还状态、时间记录与 GUI 分离。
- 本地文本读写记录操作，适合作为基础桌面应用练习。

## 目录与入口

- `智能实验室设备借还管理系统.py`

## 环境与运行

Python 3 与 Tkinter。进入当前目录后运行：

```bash
python 智能实验室设备借还管理系统.py
```

运行数据在本机生成；如加载入口要求已有 `devices.txt`，按源文件中的字段格式建立空白或虚构测试数据。

文本记录一行一个设备，字段为 `dev_id,name,model,status,borrower`，例如下面的虚构记录：

```text
DEMO-001,演示示波器,MODEL-DEMO,在库,无
```

## 验证范围与复现说明

- 这是文本存储的基础版，与 ZigBee/SQLite 的 Smart Lab 项目分开记录。
- 未上传真实设备清单、借用人或操作日志。
