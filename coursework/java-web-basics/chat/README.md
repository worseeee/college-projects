# Chat Java Web 练习

JSP 聊天室页面练习

**性质**：Servlet/JSP 分项实验。

## 功能与实现

- JSP 聊天室页面练习。
- 与班级门户分开保留，便于查看单模块实现。

## 目录与入口

- `src/main/webapp/WEB-INF/web.xml`
- `src/main/webapp/chat.jsp`

## 环境与运行

在兼容 javax.servlet 的 Servlet/JSP 容器中配置 Web 应用，编译 src/main/java 并部署 src/main/webapp。依赖容器 API，不将容器 JAR 提交到仓库。
