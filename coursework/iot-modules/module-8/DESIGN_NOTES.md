# 课程设计说明摘要

以下根据本地课程报告整理，仅作功能与实验方法说明，不替代复现实测。

本实验旨在通过设计并编写一个基于 Ollama 本地大语言模型的桌面客户端程序，使学生掌握 Python 调用本地大模型 HTTP 接口的基本方法，熟练运用 `requests` 库实现流式（stream）数据请求与解析，掌握 `tkinter` 与 `ttk` 构建多标签页图形用户界面的技术，熟练使用 `threading` 与 `queue` 实现界面线程与网络请求线程的安全通信，从而避免界面卡顿。学生还应学会设计面向不同学习场景（聊天、总结、问答、代码解析、资料检索、Prompt 实验）的提示词模板，并能够评估本地大模型在不同任务下的生成质量、响应速度与适用范围，培养工程化思维与人工智能应用开发能力。

请按照以下步骤逐步设计并编写 `OllamaClient.py`，最终实现一个完整的"本地 AI 学习实验室"客户端：

4. 实现六个功能标签页：聊天助手、文章总结、学习问答（按学科切换）、代码助手（按任务类型切换）、资料问答（导入本地 TXT 文件）、Prompt 实验（自定义角色/任务/问题三段式提示词），以及模型信息展示页。

本实验深度应用了“提示词工程”技巧，为不同 ttk.Notebook 标签页注入了系统级约束前缀：

隐私高敏感场景：无需将个人文档、企业机密代码上传至云端即可完成本地的总结与审查，实现了物理级的数据安全。
