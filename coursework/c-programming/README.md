## 环境与运行

使用 GCC/Clang 或课程指定 C 编译器，按每个含 main 的练习独立构建。多文件练习同时编译其依赖源文件，避免把所有同名 main 链接到一个程序。

```bash
gcc -Wall -Wextra -o exercise <entry.c> <required-source.c>
```
