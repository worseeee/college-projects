# 计算机网络 Packet Tracer 实验

包括点对点、共享/交换以太网、交换机学习、生成树和 VLAN 的原生仿真拓扑。

**性质**：网络协议与拓扑实验。

## 功能与实现

- 按题号保留 9 个 .pkt 拓扑文件。
- 通过设备配置和仿真模式观察转发、冲突域/广播域及 VLAN 行为。

## 目录与入口

- `实验1-1搭建仿真实验环境.pkt`
- `实验2-1熟悉常用网络设备及其互连.pkt`
- `实验3-1验证点对点协议.pkt`
- `实验3-2使用集线器构建共享式以太网.pkt`
- `实验3-3使用交换机构建交换式以太网.pkt`
- `实验3-4以太网交换机自学习和转发帧的过程.pkt`
- `实验3-5以太网的扩展（集线器和交换机的对比）.pkt`
- `实验3-6验证以太网交换机的生成树协议.pkt`
- `实验3-7划分虚拟局域网.pkt`

## 环境与运行

用兼容原文件版本的 Cisco Packet Tracer 打开对应 .pkt，检查接口、地址、VLAN、路由和协议仿真事件。

## 验证范围与复现说明

- 不包含 Cisco 安装包、课程 PPT 或现网配置备份。
