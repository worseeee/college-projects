# MFC 基础计算器

保留基础桌面应用与事件处理练习。

**性质**：C++/MFC 入门实训。

## 功能与实现

- MFC 对话框、控件和事件响应。
- 用于学习桌面应用基础，不等同三轴运动控制台。

## 环境与运行

使用 Visual Studio 及对应 MFC 工具集打开当前目录的 vcxproj 或 slnx，选择工程支持的平台构建。
