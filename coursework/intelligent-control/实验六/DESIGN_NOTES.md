# 课程设计说明摘要

以下根据本地课程报告整理，仅作功能与实验方法说明，不替代复现实测。

利用工具箱提供的 Rule Viewer (规则观察器)，我直观地观察到了输入变化对输出的动态影响 。每当调整污泥或油脂的黄色滑块，输出端的蓝色区域质心便会平滑移动，验证了控制逻辑的连续性和稳定性。此外，Surface Viewer (曲面观测器) 生成的三维映射曲面展示了输入与输出之间的整体非线性关系，这在传统控制理论中往往需要极其复杂的建模才能实现 。

模糊控制的魅力在于它不依赖于被控对象的精确数学模型，这对于洗衣机这种难以建立物理模型的场景非常高效。本次实验不仅锻炼了我的软件操作能力，更让我理解了如何平衡机器逻辑与人类经验。在未来的设计中，我希望能进一步尝试在 Simulink 环境下将模糊控制器与实际受控过程相结合，实现闭环系统的仿真分析 。
