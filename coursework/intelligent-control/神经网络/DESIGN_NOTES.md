# 课程设计说明摘要

以下根据本地课程报告整理，仅作功能与实验方法说明，不替代复现实测。

本实验要求识别 16 个十六进制字符（0~9, A~F）。

激活函数与特殊机制：隐含层选用 tansig 函数加速梯度下降；输出层选用 logsig 函数以确保输出范围在  之间。特别注意：由于本实验的输入与目标值均为严格的纯布尔逻辑值（0 和 1），必须在代码中显式关闭 MATLAB 默认的 mapminmax 数据归一化预处理机制，否则会导致网络无法收敛。

%   本脚本通过5x3点阵输入，利用BP网络实现0-F字符的二进制编码识别。

本实验旨在基于历史统计数据建立宏观经济指标与货运量之间的非线性映射模型。

本实验要求根据表1给出的历届男子跳高成绩，预测第15届的成绩。

%   本脚本通过1-14届跳高成绩训练一维BP网络，实现第15届成绩的趋势预测。

1.训练过程与拟合精度：如性能曲线所示，网络在第 204 步（Epoch 204） 完成收敛，均方误差达到 ，满足了极为苛刻的目标误差要求。从回归分析图可见，整体相关系数高达 ，表明网络对小样本序列实现了极高质量的特征提取与非线性拟合。

对于缺乏外部特征参数的小样本一维时间序列问题，通过构建“序号-目标值”的映射关系，BP 神经网络同样能够发挥出强大的泛化与预测能力。合理的归一化处理配合适度的隐含层节点数（本实验为 5 个），能有效避免小样本数据下的过拟合现象，输出符合宏观规律的预测曲线。
